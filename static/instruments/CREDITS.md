`harmonica.png` is the exception: that set has no harmonica. It is
Harmonica.svg by Sarah A Morrigan (missiridia) from Wikimedia Commons, **CC0
1.0**, flattened to the same white-on-black silhouette the others use.

All of them are painted as CSS luminance masks, so whatever the file holds
comes out in the site's green.
